DATA PROCESSING AGREEMENT (DPA)

Effective Date: 01/05/2026

Last Updated:

Between: Huria Delivery Limited ("Processor")

And: [Merchant/Partner Name] ("Controller")

1. Background

This DPA applies when Huria processes personal data on behalf of merchants.

2. Definitions

Term Definition
Personal Data Any information identifying a natural person
Processing Any operation performed on personal data
Data Subject The person whose data is processed
Sub-processor Third-party engaged to process data

3. Scope of Processing

3.1 Categories of Data Subjects

  • Customers placing orders
  • Delivery drivers
  • Merchant employees

3.2 Types of Personal Data

  • Names, contact information
  • Delivery addresses
  • Order history
  • Payment information
  • Location data

3.3 Processing Activities

  • Order management
  • Delivery coordination
  • Payment processing
  • Customer support
  • Analytics

4. Processor Obligations

Huria shall:

Obligation Implementation
Process only on documented instructions Written agreement
Maintain security measures Encryption, access control
Report data breaches Within 48 hours
Assist with data subject requests Forward within 24 hours
Enable audits Annual or on request
Return or delete data On termination

Sub-processor Service Location

5.2 New Sub-processors

  • We notify of new sub-processors
  • You may object within 14 days
  • Reasonable objections accepted

6. Data Transfers

  • Data may be transferred outside Tanzania
  • Standard Contractual Clauses apply
  • Adequacy decisions respected

7. Security Measures

Measure Description
Encryption AES-256 at rest, TLS 1.3 in transit
Access Role-based, MFA for privileged
Backup Daily encrypted backups
Monitoring 24/7 intrusion detection
Incident response Documented procedure

8. Breach Notification

If a breach occurs:

  • Notify Controller within 48 hours
  • Provide breach details
  • Cooperate on investigation
  • Implement remediation

9. Return and Deletion

On termination:

  • Data returned within 30 days
  • Then deleted within 90 days
  • Certification of deletion provided

10. Audit Rights

  • Annual audits permitted
  • 30 days advance notice
  • Confidentiality of findings

11. Liability

  • Huria liable for its own processing
  • Huria liable for sub-processors
  • Liability limited to direct damages

12. Governing Law

Tanzanian law applies.
